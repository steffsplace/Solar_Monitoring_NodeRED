# Solar Monitoring (Node-RED)

This repository contains Node-RED flows and deployment notes for solar power
monitoring and energy data integration in the Open Physics Lab.

## Contents
- `flows/flows.json` — exported Node-RED flows (versioned)
- `docs/` — deployment & operational documentation
- `docker/` — container setup (optional / future)

## Security note
Credentials are not stored in this repository. Provide secrets locally via
Node-RED credential store or environment variables.
